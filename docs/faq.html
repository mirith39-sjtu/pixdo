常见问题

没找到答案？到 GitHub Issues 反馈。

一直显示「未登录」？

检查代理是否生效，然后在「设置」页重新登录；也可以删除本地 cookies.pkl 后重试。

搜索没有结果？

检查标签拼写（推荐日文 Tag）、排序设置与代理；联想功能需要能访问 pixiv 接口。

提示 429 限流？

程序会自动等待重试，属正常现象；建议保持默认请求间隔。

R18 作品搜不到？

需要处于登录状态，且账号已开启 pixiv 的 R-18 显示设置；游客状态下不会出现 R18 结果。

删掉的图片会被重新下载吗？

只删一部分 → 视为有意保留，不再补下；整组删光 → 视为不喜欢，不再补下；一次几乎删光（≥ 九成）→ 视为批量清理，下次重新下载。也可在设置里改为「整组删除后重新下载」。

联想不出中文角色名？

试试更短的词头（如「百合园」）；部分角色名需要先查过相关标签，之后可走本地缓存命中。

动图下载后不动？

动图会自动下载帧序列并合成为 GIF，帧数多时需要等一会儿；合成完成后到相册查看即可。

会不会有封号风险？

会。短时间大量下载可能被判定为异常访问，建议保持默认间隔、单次不要过多，介意风险请使用小号。
