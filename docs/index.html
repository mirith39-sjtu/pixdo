使用步骤

Windows

  1. 开启 VPN / 代理（需能访问 pixiv）
  2. 双击 pixdo-v1.3.exe，首次运行会自动打开浏览器等待登录
  3. 在「爬取」页设置标签、数量、最低点赞与 R18 选项，点「开始爬取」
  4. 图片保存在程序目录 downloads/<标签>/safe|r18/

Android

  1. 开启 VPN / 代理
  2. 到「设置」页点「登录」，在弹出的页面中登录 pixiv 账号
  3. （下载 R18 必需）在 pixiv 网页版开启「設定 → 閲覧設定 → R-18作品の表示」
  4. 回到「爬取」页填写标签并开始，图片保存到相册 Pictures/PixivScraper/

常见问题

一直显示「未登录」？

检查代理是否生效，然后在「设置」页重新登录；也可删除本地的 cookies.pkl 后重试。

搜索没有结果？

检查标签拼写（推荐用日文 Tag）、排序设置与代理；标签联想需要能访问 pixiv 接口。

提示 429 限流？

程序会自动等待重试，属正常现象；建议保持默认请求间隔。

R18 作品搜不到？

需要登录状态，且账号已开启 pixiv 的 R-18 显示设置；游客状态下不会出现 R18 结果。

删掉的图片会被重新下载吗？

只删一部分 → 视为有意保留，不再补下；整组删光 → 视为不喜欢，不再补下；一次几乎删光（≥ 九成）→ 视为批量清理，下次重新下载。

联想不出中文角色名？

试试更短的词头（如「百合园」）；部分角色名需要先查过相关标签后走本地缓存命中。

⚠ 使用风险（必读）

本工具通过 pixiv 公开接口批量获取内容。虽然内置了请求间隔与限流自动重试，但短时间内大量下载仍可能被判定为异常访问，可能导致接口限流、账号功能受限甚至封号。建议保持默认间隔、单次下载量不要过大；介意风险请使用小号。
