Windows · Android ｜ 当前版本 v1.3

使用说明

先开启代理（需能访问 pixiv），下载见 下载页。

Windows

  1. 双击 pixdo-v1.3.exe；首次运行会自动打开浏览器等待登录，完成后自动继续
  2. 在「爬取」页填写标签（支持中文联想），设置数量、最低点赞与 R18 选项
  3. 点「开始爬取」，运行状态与进度在页面顶部显示，日志在「运行日志」窗口
  4. 图片保存在程序目录 downloads/<标签>/safe|r18/

Android

  1. 到「设置」页点「登录」，在弹出的页面登录 pixiv 账号（自动检测）
  2. 下载 R18 需先在 pixiv 网页版开启「設定 → 閲覧設定 → R-18作品の表示」
  3. 回到「爬取」页填写标签与选项，点「开始爬取」
  4. 图片保存在相册 Pictures/PixivScraper/<标签>-safe|-r18

小提示

下载时可以切到后台或锁屏，进度看通知栏（Android）；凑不够数量时可以降低最低点赞，或换一个更通用的标签；更多问题见 常见问题。
