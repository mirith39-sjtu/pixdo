v1.3 2026-10-11 · Windows / Android 双端

  • 全新界面：顶部页面分栏（爬取 / 操作说明 / 设置 / 关于）；主页面只保留常用项，运行日志单独查看；设置页集中其余选项并附功能说明
  • 运行状态面板：主页面实时显示 未开始 / 运行中 / 已完成 / 已中断、当前阶段（搜索 → 筛选详情 → 下载 x/y）与进度条
  • 删除偏好学习：根据删除行为自动统计不喜欢的标签并在排序中降权（不会直接排除）
    • 整组删除 = 明确不喜欢（权重最高，且不再补下）
    • 挑片删除（清理重复图 / 无用图）默认不计入，可在设置中开启（权重封顶）
    • 偏好按搜索标签分别学习；与搜索标签高度伴随的基础标签不会被计入
  • 删除行为判断调整：整组删除不再自动重新下载；一次几乎删光（≥ 九成）才按批量清理处理（可在设置中切换）
  • 筛选效率提醒：检查很多作品仍凑不够数量时提醒一次，可一键放宽最低点赞（附建议参考值）
  • 小众性癖过滤（R18）：内置 14 类标签库，默认过滤，可勾选允许的类别
  • 细节：条件显示控件、登录状态检测移至设置页、关于页补充风险与声明

v1.2 2026-10-07 · 双端

  • 动图（うごイラ）支持：自动下载帧序列并合成为可播放的 GIF（逐帧延迟、无限循环、600px 播放版）

  • Android：修复切后台后筛选卡住；相册文件夹改为 <标签>-safe / <标签>-r18
